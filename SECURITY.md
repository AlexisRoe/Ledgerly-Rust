# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub:
[Report a vulnerability](https://github.com/AlexisRoe/Ledgerly-Rust/security/advisories/new).

Include what you found, how to reproduce it, and the version or commit you tested. I aim to
acknowledge a report within 7 days and to tell you how I plan to handle it within 30 days.

## Scope

The Rust backend (authentication, authorization, uploads, CSV import, container image). This is a learning project, but it is built to be hardened, so reports are taken seriously.

## Supported versions

Only the latest commit on `main` is supported.
