Course

Rust for TypeScript developers

Taught on Ledgerly-Rust: by the end you can open any file in crates/, say what it does, and make a small change yourself.

How to use this course
  • Do the lessons in order. Each takes 10–15 minutes and gives you one concrete skill.
  • Each lesson opens with recall questions on earlier lessons. Answer them from memory before you open them. The effort of remembering is what makes it stick.
  • Code captions with a path, such as crates/expenses/src/lib.rs:20, open the real file in VS Code. Read it there, with the surrounding code.
  • Hands-on exercises live in learn/playground/, a small cargo project with failing tests. Its README explains how to run them.
  • Each section ends with a printable cheat sheet. Come back to those, not to the lessons.
  • Stuck? Ask the agent in Claude Code. That's what it's there for.
