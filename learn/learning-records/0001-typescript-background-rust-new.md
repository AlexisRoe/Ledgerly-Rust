# Strong TypeScript background; Rust is new

The learner knows TypeScript well and is new to Rust. They built Ledgerly-Rust with a coding agent so they would have real code to learn from. Lessons can assume TS fluency (interfaces, generics, union types, narrowing, async/await, npm tooling) and use it as the anchor for every new Rust idea. Rust concepts start at zero.

**Evidence:** stated by the learner when requesting the course (2026-11-17).

**Implications:** Don't explain programming basics. Do explain anything Rust-specific, especially ownership, borrowing and lifetimes, which have no TypeScript equivalent. Mark clearly where an analogy breaks. Lessons compare with TypeScript only, not Java (learner's choice).
