Startup

main: config → logging → panic hook → telemetry → Tokio runtime → block_on(run). run: stop signal → database::connect → database::verify (schema) → seed::demo_data → App::bind (modules, ports) → serve (until SIGTERM, drain 30 s) → pool.close. Errors: ConfigError/StartupError → failed_to_start → exit code 1.
