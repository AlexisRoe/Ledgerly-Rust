Errors

callers handle#[derive(thiserror::Error)] enum; one variant per reaction; carry data; #[from] for sources
callers reportanyhow::Result<T>; .context("…") / .with_context(|| …); print with {:#}
neversecrets, SQL, paths in messages users see

Parse, don't validate

Parse at the edge (request, row, env var); pass typed values inward.

Construction

new(…) -> Self / -> Result<Self, E>few required inputs
impl Default + S { x: 1, ..Default::default() }many fields with sensible defaults (hand-write if 0 isn't sensible)
builder: T::builder(req).opt(x).build()?required + optional parts, validation of the combination; #[must_use]

Naming and API

as_ / to_ / into_free borrow / costly → owned / consumes self
gettersname(), not get_name(); return &str, &[T]
parameters&str to read, impl Into<String> to store, impl AsRef<Path> for paths
deriveDebug always (redact secrets); Clone, PartialEq, Eq, Hash, Default where meaningful
#[must_use]pure getters, builders, results nobody should ignore
#[non_exhaustive]public enums/structs of published libraries; not inside one workspace

Boundaries

  • Module: organisation, pub(crate). Crate: enforced wall, acyclic graph, parallel builds.
  • Features are additive; test helpers behind feature = "testing" in [dev-dependencies].
  • Published crates: new enum variant, new pub field, removed item = breaking. cargo-semver-checks.
