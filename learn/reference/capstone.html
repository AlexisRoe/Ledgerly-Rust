Building a service from scratch

Section 22 as a checklist for your next Rust service. Reference solution: learn/capstone/.

Set up

Layers, inside out

domainnewtypes with private fields and parse constructors; a thiserror enum; no I/O, no async
storeport: trait Store: Debug + Send + Sync (BoxFuture methods if async); adapter with RwLock; check-and-insert under one lock
web#[derive(Clone)] AppState of Arcs; handlers return Result<_, ApiError>; one exhaustive IntoResponse
workersown their state; fed by mpsc; select! over recv() and a tick; end on None
mainconfig, tracing, bind (no unwrap), spawn workers, serve(…).with_graceful_shutdown(ctrl_c), await workers

Testing

Unit tests per layer; HTTP tests in-process; a test that shares the store across threads; worker tests that drop the sender and await the task.

Review

cargo fmt --check · cargo clippy --all-targets -- -D warnings · pedantic pass with #[expect(…, reason)] · cargo test · cargo doc --open · the checklist in .
