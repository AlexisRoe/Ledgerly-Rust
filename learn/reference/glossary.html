Glossary

The words this course uses, each defined once. The nearest TypeScript idea is in brackets where one exists. (For Ledgerly's business vocabulary, such as claimant, approver or reimburse, see the repo's own GLOSSARY.md.)

Tooling

toolchainA compiler, cargo and standard library at one version, managed by rustup. (a Node version)
editionAn opt-in language dialect per crate (2024 here); editions mix freely.
packageOne Cargo.toml and the crates it builds. (an npm package)
crateOne unit of compilation: a library (lib.rs) or a binary (main.rs).
workspaceSeveral packages sharing one lock file and target/. (a pnpm workspace)
featureAn optional, compile-time part of a crate, switched on by dependents.
lint levelallow, warn, deny (overridable error), forbid (final error).

Code organisation

moduleA namespace in the crate's tree, declared with mod; usually one file.
pathAn item's address: crate::domain::Action, super::x, std::sync::Arc.
itemAnything declared at module level: fn, struct, enum, trait, impl, const, mod, use.
visibilityWho may use an item: private (default), pub(crate), pub. (export)
re-exportpub use: publishing an item at a new path. (export { X } from)
facadeA Ledgerly crate's deliberately small public API.
attribute#[…] / #![…]: a compile-time instruction on an item.
macroCode that writes code at compile time, called with ! or used as a derive/attribute.

Types

structA named type with fields. (an interface plus its data)
tuple struct / newtypeA struct with unnamed fields; with one field, a zero-cost distinct wrapper. (a branded type)
enumA type with a fixed set of variants, each optionally carrying data. (a discriminated union)
variantOne case of an enum, such as ExpenseStatus::Draft.
Option<T>Some(T) or None: a value that may be absent. (T | undefined)
Result<T, E>Ok(T) or Err(E): an operation that may fail.
unit ()The type with one value: "nothing to return". (void)
sliceA borrowed view into contiguous data: &[T], &str.
nicheAn impossible bit pattern (a null reference) that an enum reuses as its tag, so Option<&T> costs nothing.
monomorphisationCompiling one specialised copy of a generic function per type it's used with.
release profileCargo's optimised build settings (--release); tests use the unoptimised dev profile.
genericA type or function with type parameters, Vec<T>; monomorphized per use.
type aliastype X = …;: a new name, not a new type.

Ownership

ownerThe variable or field responsible for a value; exactly one at a time.
moveTransfer of ownership by assignment, passing or consuming; the old name becomes unusable.
dropReleasing a value (memory, transaction, lock) when its owner goes out of scope.
CopyA trait for small values that are copied instead of moved.
CloneA trait for explicit duplication with .clone(); cost depends on the type.
borrow / referenceTemporary access without ownership: &T (shared, read) or &mut T (exclusive, write).
borrow checkerThe compiler pass enforcing "many readers or one writer, never outliving the value".
lifetimeA name ('a) for how long a borrow is valid; 'static = the whole program.
lifetime elisionThe three rules that fill in lifetimes you don't write.
interior mutabilityChanging data through a shared &, made safe by a type (Cell, RefCell, Mutex).
RAIIA resource released by its owner's Drop at scope end. (try/finally, using)
Cow"Clone on write": borrowed or owned data behind one type.
smart pointerA pointer type that owns its target: Box (one owner), Rc/Arc (shared).

Behaviour

method / associated functionA function in an impl with / without a self parameter. (instance / static method)
traitA set of methods a type implements explicitly. (an interface, nominal)
trait boundA requirement on a type parameter: T: Display. (T extends …)
trait objectdyn Trait behind a pointer: an implementation chosen at runtime.
deriveGenerating a trait implementation with #[derive(…)].
Send / SyncSafe to move to / share between threads.
associated typeA type an impl fixes once, like Iterator::Item.
blanket implAn impl for every type meeting a bound: impl<T: Display> ToString for T.
extension traitA local trait adding methods to a foreign type; works where imported.
orphan rule / coherenceAn impl needs a local trait or a local type, so each (trait, type) has one impl.
dyn compatibleA trait usable as dyn Trait: no generic methods, no Self by value, no async fn.
vtableThe table of method pointers behind a dyn Trait.
typestateStates as types, so illegal transitions don't compile.
PhantomDataA zero-sized field marking a type parameter as used.
closureAn anonymous function capturing its environment: |x| x + 1. (arrow function)
iteratorA lazy sequence with adapters (map, filter) and consumers (collect).

Control flow and errors

expression / statementCode that produces a value / code ending in ; that produces ().
patternA shape to match and destructure, used in let, match, parameters.
exhaustiveCovering every possible value; required of every match.
refutable patternA pattern that might not match (Some(x)); needs if let / let … else.
? operatorUnwraps Ok/Some, or returns the converted error from the function.
panicUnwinding on a bug (failed unwrap, index out of bounds); not for expected errors.

Async

futureA lazy async computation; does nothing until awaited. (a Promise that doesn't start itself)
runtimeThe library that polls futures and schedules tasks: Tokio. (Node's event loop)
taskA future spawned onto the runtime with tokio::spawn, possibly on another thread.
wakerThe handle a future leaves behind so the executor knows when to poll it again.
executorThe loop that polls woken futures (Tokio's scheduler; a toy block_on).
PinA pointer whose target won't move again; needed for self-referential futures.
cancel safetyWhether dropping a future mid-way loses work; matters in select! loops.
blockingLong work between two .awaits; belongs in spawn_blocking.
actorA task that owns some state and is driven by messages on a channel.
atomicA lock-free, thread-safe integer or flag (AtomicUsize).
extractorAn axum handler parameter type that pulls its value out of the request.
