Futures under the hood

async fn = a state machine enum, one state per .await. Lazy until polled.

Cancellation

  • Drop = cancel at the current .await: select! losers, timeout, abort(), client disconnect, dropped JoinSet.
  • Cancel-safe in select! loops: mpsc::recv, sleep, watch::changed. Not: read_exact, multi-step writes. Check Tokio's docs.
  • Durable state in the database (transactions, outbox) makes cancellation harmless.
  • JoinSet: spawn, join_next().await in completion order; aborts the rest on drop.

Blocking

>10–100 µs without .await = blocking. CPU work, std::fs, sync clients → tokio::task::spawn_blocking(move || …).await → Result<T, JoinError>.
