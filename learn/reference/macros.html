Attributes

#[…] → next item. #![…] → enclosing item (file/module/crate). All act at compile time.

AttributeKindEffect
#[derive(Debug, Clone, …)]generatetrait impls
#[derive(thiserror::Error)] + #[error], #[from]generate / configureerror types (lesson 56)
#[derive(Serialize, Deserialize)] + #[serde(…)]generate / configureJSON (lesson 68)
#[test], #[tokio::test]generatetest functions (async with tokio)
#[cfg(test)]conditionalonly in test builds
#[cfg(any(test, feature = "testing"))]conditionaltests or a feature
#![cfg_attr(cond, attr)]conditionalapply attr only if cond
#![forbid(unsafe_code)]linterror, not overridable
#[must_use]lintwarn if the result is ignored
#[expect(lint, reason = "…")]lintallow once, documented; fails if unneeded
#[allow(lint)] / #[deny(lint)]lintset a level
