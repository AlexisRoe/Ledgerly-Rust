The rules

  1. Every value has one owner.
  2. Assigning, passing by value, for x in coll and self-methods move ownership; the old name is dead (unless the type is Copy).
  3. When the owner leaves scope, the value is dropped (memory freed, transaction rolled back, lock released…).
  4. Borrow instead of moving: many &T or one &mut T, never both at once.
  5. A reference must not outlive its value. Borrows end at their last use.

Copy vs Clone

Copy: implicit bitwise copy; only for types without heap ownership. Ids, Actor, Money, Role, numbers, &T. Clone: explicit .clone(); cost depends on the type. String/Vec: deep copy. Arc/PgPool: a new handle to the same thing.

Lifetimes (reading)

&'static str: valid for the whole program (literals). '_: some lifetime, unnamed. fn f<'a>(x: &'a T) -> &'a U: the result borrows from x. Elision: one input reference or &self → the output borrows from it.
