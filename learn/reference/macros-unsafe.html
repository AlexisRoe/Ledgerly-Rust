unsafe

  • Allows: raw pointer deref, unsafe fn / FFI calls, mutable statics, unsafe trait impls, union fields. Nothing else; all other checks still run.
  • Wrong use = undefined behaviour, which may appear to work.
  • Conventions: # Safety doc on every unsafe fn; // SAFETY: on every block; wrap in a safe API.
  • Ledgerly: unsafe_code = "forbid" (workspace) + #![forbid(unsafe_code)] (each crate). Lints don't reach dependencies.
