Ownership and lifetimes in depth

Section 15 on one page. The basics are on the ownership rules card.

Lifetime elision

  1. Each input reference gets its own lifetime.
  2. Exactly one input lifetime → all output references get it.
  3. &self / &mut self → all output references get self's.

Otherwise: E0106. Give the output the lifetime of exactly the inputs it borrows from.

'static

&'static Tvalid for the whole program: literals, statics
T: 'staticholds no short borrows: every owned type (String, Arc<_>, u32)
tokio::spawn, thread::spawnneed 'static: clone (often an Arc), then move
Box<dyn Trait>= Box<dyn Trait + 'static>; write + 'a to borrow
thread::scopeborrows locals, no 'static needed

Drop and mem

  • Locals drop in reverse declaration order; fields in declaration order. drop(x) ends early.
  • let _ = guard() drops now; let _guard = guard() at scope end.
  • Drop can't be async or fail: use commit().await?-style methods for that.
  • mem::take(&mut x) (leaves default) · mem::replace(&mut x, y) · opt.take().
