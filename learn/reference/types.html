Newtypes and generics

pub struct TeamId(Uuid);: distinct type, zero cost, no casts. TS brands are forgeable; newtypes aren't. struct Versioned<T> { value: T, version: Version } ≈ interface Versioned<T>. type X = …; is an alias (same type). Read nested types outside in: Result<Option<Versioned<Expense>>, E> = "may fail; else maybe an expense with version".
