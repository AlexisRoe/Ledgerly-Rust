A function's last line is self.rank() >= other.rank(). What would a semicolon at the end change?
The body would end in a statement, so it would return (). With -> bool declared, that's E0308 (mismatched types).
Name the four places a path can start inside a crate (besides external crate names).

Mixed questions

Which of these compiles?

  • const LIMIT = 100;
  • const LIMIT: u32 = 100;
  • let LIMIT: u32 = 100; LIMIT = 5;
  • let mut limit: u32 = "100";
Constants need a type. Reassigning a non-mut binding fails, and "100" is text, not u32.

You created crates/teams/src/web/invite.rs. Which line in which file makes it part of the crate?

  • use invite; in crates/teams/src/lib.rs
  • mod invite; in crates/teams/src/web/mod.rs
  • mod web::invite; in crates/teams/src/lib.rs
  • pub use invite; in crates/teams/Cargo.toml
The parent module declares its child. web's code is in web/mod.rs, so that's where mod invite; goes.

In crates/expenses/src/web/mod.rs, what's self::dto::ExpenseResponse?

  • A type in the external crate called dto
  • A type in the crate root's dto module
  • A type in web's child module dto
  • A type in the parent of web's module
self is the current module (web), and dto is its child, declared by mod dto; in the same file.

Which statement about ledgerly_expenses's public API is true?

  • Every pub item in any of its modules
  • Only what lib.rs exposes, mainly via pub use
  • Everything, since all crates share one workspace
  • Only items listed in its Cargo.toml exports
All its modules are private, so the public API is exactly pub fn routes and the pub use lines in lib.rs.

(Section 1) Which command shows that rust-toolchain.toml is in effect?

  • cargo check
  • rustup show
  • cargo tree
  • just --list
rustup show prints the active toolchain and why it was chosen ("overridden by …/rust-toolchain.toml").

(Section 1) A crate's manifest has [lints] workspace = true. What does that do?

  • Runs clippy automatically on every cargo build
  • Applies the root's [workspace.lints] levels to it
  • Shares one target folder across workspace crates
  • Adds the crate to the workspace members
Opting in to the shared lint table is per crate. Membership comes from members = ["crates/*"].

Notes on 4
Role, UnknownRole, ALL, includes and as_str are public. rank is private on purpose: the doc comment on Role says there's deliberately no ordering, so that "at least an approver" can only be asked through includes. Keeping rank private enforces that.
