Recall

Answer out loud, then open
The three lifetime elision rules?
Each input reference gets its own lifetime; with exactly one input lifetime, outputs get it; with &self/&mut self, outputs get self's. (80)
&'static str vs T: 'static?
A reference valid for the whole program vs a type that holds no non-static borrows (every owned type). (82)
Cell, RefCell, Mutex: which are Sync?
Only Mutex (and RwLock, atomics, OnceLock). (84)
What does mem::replace(&mut x, y) return?
The old value of x; x now holds y. (86)

Mixed questions

fn pick(a: &str, b: &str) -> &str fails to compile. Which error do you get?

  • E0382 use of moved value
  • E0106 missing lifetime specifier
  • E0499 two mutable borrows
  • E0308 mismatched types
Two inputs, no self: elision can't choose. (80)

A struct you keep in axum's shared state holds a &'a PgPool. Is that a good design?

  • Yes, borrowing is always cheaper than owning data
  • No, long-lived state should own it, as a clone
  • Yes, as long as 'a is written out explicitly
  • No, because PgPool values can never be borrowed
Router state must be 'static; PgPool is a cheap Arc clone. (81, 82)

(Async, Part I) Why does Ledgerly clone self.storage before tokio::spawn(async move { … })?

  • Because storage must be copied for thread safety
  • The task must own what it uses: 'static
  • Because async blocks cannot read struct fields
  • To make the background task start sooner
A spawned task may outlive self. (63, 82)

You count words into a HashMap<String, usize>. Which line is idiomatic?

  • m.insert(w, m.get(&w).unwrap() + 1);
  • *m.entry(w).or_insert(0) += 1;
  • m[&w] += 1;
  • m.get_mut(&w).map(|c| c + 1);
The entry API: one lookup, works for new and existing words. m[&w] panics on a missing key and isn't assignable for HashMap. (83)

(Errors, Part I) let tx = pool.begin().await?; … then a ? returns early. What happens to tx?

  • It stays open until the connection pool closes
  • It's dropped, and dropping rolls it back
  • It's committed, because no error happened in it
  • The compiler rejects the early return there
RAII: the transaction's Drop rolls back. Only commit() keeps the work. (69, 86)

A &self method must update a cache, single-threaded. What fits?

  • static mut cache
  • RefCell<HashMap<K, V>> field
  • change the method to take self
  • Cell<HashMap<K, V>> field
Cell only moves values in and out; you need references into the map. static mut needs unsafe. (84)
