1. Let the tools review first

Pedantic lints are opinions (must_use_candidate, missing_errors_doc, casts). Fix the ones you agree with; for the rest, an #[expect(clippy::…, reason = "…")] documents the decision, as Ledgerly does with Money::cmp.

Check yourself

Clippy pedantic flags a cast you know is safe. What's the Ledgerly-style response?

  • Add allow(clippy::pedantic) to the whole crate root
  • An expect attribute with a written reason
  • Ignore it, since pedantic lints are optional
  • Rewrite the code until clippy stops complaining entirely
#[expect] also warns if the lint stops firing, so stale exceptions don't pile up.

You add a PgLinkStore. What should change in web.rs?

  • Every handler, to call the database directly
  • Only awaits, if the port's methods become async
  • Nothing at all, not even the method calls
  • The router, which needs one route per store
The port isolates the adapter; only the port's shape (sync vs async) leaks into callers.
