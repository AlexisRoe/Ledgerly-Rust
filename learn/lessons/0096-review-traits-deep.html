Associated type or type parameter: the rule of thumb?
One sensible answer per implementing type → associated type; callers choose → parameter. (88)
Three things that make a trait not dyn-compatible?
Generic methods, methods returning or taking Self by value, async fn / -> impl Trait methods (unless where Self: Sized). (92)
The orphan rule in one sentence?
You may implement a trait for a type only if the trait or the type is local. (91)
What does PhantomData<S> cost?
Nothing: it's zero-sized. (95)

Mixed questions

A trait you design will be stored as Arc<dyn Notifier> and needs an async send. What signature?

  • async fn send(&self, msg: &str) -> Result<(), E>;
  • fn send<'a>(&'a self, msg: &'a str) -> BoxFuture<'a, Result<(), E>>;
  • fn send(&self, msg: &str) -> impl Future<Output = Result<(), E>>;
  • fn send<F: Future>(&self, msg: &str) -> F;
Only the boxed future is one nameable type that a vtable can hold. (92)

You implement From<Uuid> for ExpenseId. What do you get for free?

  • Nothing; Into needs its own separate impl
  • uuid.into() to ExpenseId, through a blanket impl
  • Display and Debug for ExpenseId as well
  • TryFrom<String> for ExpenseId, through the same impl
impl<T, U: From<T>> Into<U> for T. (51, 90)

(Lifetimes) A method returns impl Iterator<Item = &str> over self.lines. What does the &str borrow from?

  • Nothing; the iterator copies each line out
  • From self, by the third elision rule
  • From a static buffer inside the iterator
  • From the caller's own stack frame only
Rule 3: with &self, output references get self's lifetime. (80, 89)

Which design keeps a Vec of claims in different states?

  • Typestate, with one separate Claim type per state
  • One Claim type with a status enum field
  • A PhantomData field holding every possible state
  • A blanket impl over all the marker types
Claim<Draft> and Claim<Approved> are different types. (95)

(Interior mutability) A &self method on a shared, thread-safe cache must insert. Field type?

  • RefCell<HashMap<K, V>>
  • RwLock<HashMap<K, V>>
  • Cell<HashMap<K, V>>
  • PhantomData<HashMap<K, V>>
Thread-safe and read-mostly: RwLock (or Mutex). (84)
